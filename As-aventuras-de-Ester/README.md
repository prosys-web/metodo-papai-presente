# Método Papai Presente — As Aventuras da Ester

Cada episódio fica em sua própria pasta, seguindo sempre esta estrutura:

```
episodio-01/
  index.html      <- o roteiro vivo do episódio
  audio/
    audio01.mp3
    audio02.mp3
    ...
    audio08.mp3
```

## Como publicar um novo episódio

1. Crie uma pasta nova, por exemplo `episodio-02/`.
2. Coloque o arquivo do episódio dentro dela, sempre nomeado `index.html`.
3. Crie a subpasta `audio/` dentro da pasta do episódio e coloque os áudios gravados (audio01.mp3 até audio08.mp3).
4. Suba (commit + push) para o GitHub.
5. O episódio ficará disponível em:
   `https://SEU-USUARIO.github.io/metodo-papai-presente/episodio-02/`

Nenhuma configuração extra é necessária — o GitHub Pages já serve todas as pastas automaticamente.
